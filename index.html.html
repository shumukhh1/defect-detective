How it works

  • MVTec AD · bottle: 229 normal + 63 defective
  • Resize 224×224, ImageNet normalization, augmentation
  • MobileNetV2 (frozen) + new classifier layer
  • 8 epochs · Adam · weighted cross-entropy
💡 The model catches every defective bottle. The price is a few extra false alarms, which is why threshold tuning is our next step.

Honest limitation: the two datasets are unpaired. We can't link a specific bottle defect to a specific machine condition, so each part is evaluated separately.

Limitations

  • AI4I is simulated, not real factory data
  • Small bottle test set (44 images, 9 defective)
  • Both datasets are imbalanced
  • Feature importance ≠ physical cause

Next steps

  • Verify splits and seeds in notebooks
  • Tune threshold to cut false alarms
  • Test more MVTec categories
  • Cross-validation + more interpretability
